# Yale Migration & Education Consultants — Document Library

Reorganized 5 July 2026. Every file was audited page-by-page before filing.
The library is split into **two tracks by audience** so internal manuals and
client documents never get mixed up again.

## 01 INTERNAL SOPs - STAFF PROCESS MANUALS  (staff only)
One subfolder per visa service line. Each SOP exists as DOCX (editable
master) + PDF (letterhead export); three also have an infographic PNG.
All follow the same 8-section template: Purpose, Scope, Roles (RMA vs
Consultant), Tools, Document Management (YM-2026-xxxxx client codes,
10 sub-folders), Step-by-step Procedure, QC Checklist, Compliance.

| STUDENT VISA 500 | SOP-SV-001 | Enrolment → CoE → Genuine Student → lodgement |

## 02 CLIENT-FACING - CHECKLISTS FEES & GUIDES  (send to clients)
Document checklists, fee schedules and pathway guides, grouped by visa.
Naming convention: `<subclass> CHECKLIST - <applicant type> - <variant>`.
Key money documents: `500 FEES AND CHARGES - APPENDIX A.docx` (VAC $2,500,
show-money $29,710) and `407 CLIENT CHECKLIST & FEE QUOTE.docx` (total $4,060).
